# 📊 Trading Journal

Ein modernes, komplett **offline-fähiges** und datenschutzfreundliches Trading Journal als schöne Web-App. 

Perfekt für Daytrader, Swingtrader und alle, die ihre Trades professionell tracken und analysieren wollen.

## ✨ Highlights

- 📝 Trades superschnell loggen mit Psychologie-Tracking
- 📈 Automatische P&L-Berechnung + Equity Curve
- 🔍 Leistungsstarke Filter, Suche & Sortierung in der Historie
- 📊 Detaillierte Analysen (Symbol, Strategie, Emotion, Wochentag)
- 📤 Export als CSV oder JSON + Import
- 🌒 Schönes Dark-Trading-Design (Tailwind + Chart.js)
- 🔐 100% lokal im Browser – keine Daten verlassen deinen Rechner
- 🚀 Direkt nutzbar über GitHub Pages

## 🚀 Direkte Verwendung (sofort loslegen)

### Variante 1: GitHub Pages (empfohlen)

1. Dieses Repository in deinem GitHub-Account öffnen
2. Gehe zu **Settings** → **Pages**
3. Unter "Build and deployment" → Source: **Deploy from a branch**
4. Branch: `main`, Ordner: `/ (root)`
5. Auf **Save** klicken
6. Warte 1–2 Minuten – deine Trading Journal App ist dann live unter:
   `https://<dein-username>.github.io/trading-journal/`

### Variante 2: Lokal starten

```bash
git clone https://github.com/AI-MSD1110/trading-journal.git
cd trading-journal
```
Dann einfach die Datei `index.html` mit einem Doppelklick im Browser öffnen.

## 📋 So funktioniert es

### 1. Trade loggen
- Klicke auf **+ Trade hinzufügen**
- Fülle die Felder aus (Symbol, Long/Short, Einstieg, Ausstieg, Größe, Gebühren)
- Wähle Setup(s) und deine Emotion
- Schreibe deine Learnings in die Notizen
- Speichern → P&L wird automatisch berechnet

### 2. Dashboard & Analyse
- Sieh sofort deine wichtigsten KPIs
- Equity Curve zeigt deine Performance über die Zeit
- Analysiere, welche Setups und Emotionen bei dir am besten funktionieren

### 3. Daten sichern
- **Export CSV** → für Excel / Google Sheets
- **Export JSON** → vollständiges Backup
- **Import JSON** → Daten wiederherstellen

## 🛠️ Technik

- Reine Frontend-App (kein Backend nötig)
- Tailwind CSS (Play CDN)
- Chart.js für schöne Diagramme
- localStorage für Datenspeicherung
- Voll responsive (Desktop + Mobile)
